# 管风琴调音巡检台

给管风琴维护人员在现场使用的调音巡检前端：选定场馆与音栓后逐管录入测量数据，自动标记需要复检的音管，并按当前待复检情况生成维护报告。**所有记录只保存在浏览器（localStorage）中，不向任何服务器发送。**

## 功能

- **现场录入**：场馆 + 音栓 + 音管编号，录入音高、音分偏差、温度、湿度、簧片状态（正常 / 异常及现象）与备注；提交前实时提示本次是否会被标记。
- **修订记录**：同一音管（场馆 + 音栓 + 编号，编号忽略大小写与首尾空格）再次保存时，当前值更新，旧值进入修订历史，最多保留 3 版。
- **待复检规则**：音分偏差绝对值超过 10 cent（±10 边界不算）或簧片异常，保存时自动生成一条待复检痕迹。
- **复查闭合**：只有当前值已恢复正常时才能点「复查合格 · 结束待办」；录入合格值不会自动关闭待办，闭合后异常痕迹仍保留在档案中可追溯。
- **维护报告**：按场馆 → 音栓汇总当前待复检音管（偏差超限 / 簧片异常数量），点击异常行跳转回巡检页并滚动、高亮定位到该音管；支持打印 / 存为 PDF。
- **本地存档**：数据仅存于浏览器 localStorage，读取时做结构清洗容错；隐私模式写入失败会给出提示。

## 代码结构（数据 / 存档 / 界面分离）

| 文件 | 职责 |
| --- | --- |
| `src/types.ts` | 数据类型层：测量值、音管档案、异常痕迹、存档结构 |
| `src/domain.ts` | 领域逻辑层：异常判定、保存归档、复检闭合、报告汇总（纯函数，不依赖 React / 存储） |
| `src/storage.ts` | 本地存档层：localStorage 读写、数据清洗、清空 |
| `src/useInspectionStore.ts` | 状态层：把领域操作与存档连接起来的 React hook |
| `src/components/` | 界面层：筛选面板、录入表单、音管列表、维护报告 |
