# hxyfront-62005 管风琴音管调音记录

给管风琴维护人员使用的**现场巡检台**：选定场馆与音栓后，逐根录入音管的音高、音分偏差、温湿度、簧片状态与备注；同一音管再次保存时更新当前值并自动留 3 版修订记录；偏差超 10 音分或簧片异常自动标记待复检，复查合格只销项、异常痕迹永久留档；维护报告按当前待复检情况汇总，点异常行可直接定位到那根音管。

## 功能

- **场馆 / 音栓管理**：内置教堂、音乐厅示例数据，可现场新增；音栓按主音栓 / 簧片音栓 / 混合音栓 / 低音管分类。
- **逐管录入**：音管编号、音高、音分偏差、温度、湿度、簧片状态（正常 / 异常）、备注。
- **修订记录**：同一编号再次保存 → 当前值更新，旧值进入修订记录，最多保留 3 版；曾触发异常的旧版会标注当时原因。
- **待复检规则**：`|音分偏差| > 10` 或簧片异常即标记；待复检期间重复异常会刷新同一条痕迹的最近观测时间；读数恢复正常**不会**自动销项，只能点“复查合格”。
- **异常痕迹**：复查合格后待办结束、读数不变，原异常记录标记为“已复查合格”并永久保留；销项后再次异常会新增一条痕迹。
- **维护报告**：按场馆汇总当前待复检音管（按音栓分组、原因标签、最近观测、备注），底部列出本周期已处理异常；点击任意异常行跳回巡检台并高亮、展开、滚动到该音管；支持打印 / 存 PDF。
- **仅本地存储**：所有记录保存在浏览器 `localStorage`（键名 `organ-inspection-archive-v1`），无任何网络上报；清除站点数据即删除记录。

## 代码结构（数据类型 / 本地存档 / 界面分层）

```
src/
├── types.ts                  # 数据类型层：Venue / Stop / PipeRecord / Revision / AnomalyTrace 等
├── domain/
│   └── inspection.ts         # 业务规则：偏差判定、留版、待复检与痕迹、排序
├── storage/
│   └── archive.ts            # 本地存档层：localStorage 读写、首次示例数据
├── hooks/
│   └── useInspectionStore.ts # 状态层：单一存档 + 变更自动写回
├── components/
│   ├── SelectorBar.tsx       # 场馆 / 音栓选择与新增
│   ├── EntryForm.tsx         # 音管测量录入
│   ├── PipeTable.tsx         # 音管清单、待复检标记、修订与痕迹展开
│   └── ReportView.tsx        # 维护报告（汇总 + 点击定位）
└── App.tsx                   # 页面组装与跨页定位
```
